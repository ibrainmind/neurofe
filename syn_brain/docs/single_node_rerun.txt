HOW TO RE-RUN THE SINGLE-NODE VIRTUAL-TMS STUDY
===============================================

Produces: syn_brain/reports/single_node_tms_study.pdf
Results, figures and logs are NOT in git (syn_brain/.gitignore); they are
regenerated by the steps below.


1. SETUP (once, on a new machine)
---------------------------------

  git clone <repo> && cd neurofe
  source setup_venv.sh        # creates .venv, installs everything, runs the tests,
                              # and leaves the environment activated
                              # (or: bash setup_venv.sh, then source .venv/bin/activate)
  Options: PYTHON=python3.11, RECREATE=1, SKIP_TESTS=1,
           TORCH_INDEX_URL=https://download.pytorch.org/whl/cpu  (CPU-only torch)

  Data: the leadfield, connectome and distances (from PyTepFit, MIT license) are
  in git under syn_brain/external/pytepfit/, so nothing else is needed for this
  study. PyTepFit's real TMS-EEG file (11.5 MB, only for calibrate_teacher.py) is
  fetched by setup_venv.sh, or by hand:
      bash syn_brain/scripts/fetch_pytepfit_data.sh
  To use another copy of the data: export SYN_BRAIN_PYTEPFIT_DATA=/path/to/data

  Check (about 40 s):
      PYTHONPATH=. .venv/bin/python -m pytest syn_brain/tests -q


2. ONE COMMAND
--------------

From the repo root:

  bash syn_brain/scripts/run_single_node_tms.sh

  Time: ~2 min analysis + ~25 min (E1-E7, 372 models) + ~20 min (E8, 30 models)
  with 4 parallel processes on 4 CPU cores. CPU only; no GPU needed.

  Options (environment variables):
    NPARTS=8                  more parallel processes on a bigger server
                              (1 core each; wall time ~ proportional to 1/NPARTS
                              until each part has few models)
    ITERS=300                 Adam iterations per model (report uses 300)
    STEP=analyse|train|report only one stage
    PYTHON=/path/to/python    interpreter to use (default .venv/bin/python)

  Examples:
    NPARTS=16 bash syn_brain/scripts/run_single_node_tms.sh
    STEP=report bash syn_brain/scripts/run_single_node_tms.sh    # rebuild PDF only

  On a remote server, run it detached so it survives logout:
    nohup bash syn_brain/scripts/run_single_node_tms.sh > sn_tms_run.log 2>&1 &
    tail -f sn_tms_run.log syn_brain/logs/sn_tms_main_part0.out


3. THE SAME STEPS BY HAND
-------------------------

  export PYTHONPATH=.
  # 1) Fisher / Cramer-Rao bounds, feature elasticities, tonic-drive sweep
  .venv/bin/python -m syn_brain.scripts.single_node_tms analyse
  # 2) backprop fits E1-E7 (4 parts in parallel)
  for p in 0 1 2 3; do
    .venv/bin/python -m syn_brain.scripts.single_node_tms train --only E1,E2,E3,E4,E5,E6,E7 --part $p --nparts 4 &
  done; wait
  # 3) temporal hold-out E8
  for p in 0 1 2 3; do
    .venv/bin/python -m syn_brain.scripts.single_node_tms train --only E8 --part $p --nparts 4 &
  done; wait
  # 4) figures + summary.json, then the PDF
  .venv/bin/python -m syn_brain.scripts.single_node_tms_figures
  .venv/bin/python -m syn_brain.scripts.single_node_tms_report

  Before re-training, delete old parts, or they are merged with the new ones:
    rm -f syn_brain/results/single_node_tms/train*_part*of*.npz


4. WHERE THINGS ARE
-------------------

  core/node.py                      single-node JR simulator, programmable virtual-TMS
                                    input (pulses, E/I targeting, tonic drive p)
  scripts/single_node_tms.py        protocols, experiments E1-E8, analyse/train
  scripts/single_node_tms_figures.py  figures -> results/single_node_tms/fig_*.png,
                                    summary.json
  scripts/single_node_tms_report.py   PDF layout (reportlab)
  scripts/single_node_tms_text.py     report text; every number is read from
                                    analysis.json / summary.json
  scripts/run_single_node_tms.sh    one-command runner
  docs/single_node_study_plan.txt   follow-up plan (network drive, disease
                                    markers, fitting methods)
  docs/background_drive_note.txt    open item: background drive and neurofe's
                                    Laplacian coupling
  scripts/pd_connectivity_plan.py   builds reports/pd_connectivity_study_plan.pdf
                                    (connections between JR nodes, early PD);
                                    needs no results:
                                      PYTHONPATH=. .venv/bin/python -m syn_brain.scripts.pd_connectivity_plan

  Superseded: scripts/single_node.py and scripts/single_node_figures.py are an
  earlier, unfinished version of this study (amplitude sweep only). Kept for
  reference; use single_node_tms*.py instead.


5. ADDING AN EXPERIMENT
-----------------------

  - New stimulus: add a Stim(...) to STIMS in core/node.py (pulses, to_i, tonic).
  - New protocol: add a list of stimulus names to PROTOCOLS in
    scripts/single_node_tms.py.
  - New experiment: append jobs in build_jobs() with a new exp="E9" tag, run
        ... single_node_tms train --only E9 --part $p --nparts N
    and add its figure in single_node_tms_figures.py.
  - Suggested first: E7 at p >= 120 (see docs/background_drive_note.txt).

Numbers can differ slightly between machines (thread scheduling, BLAS), but
conclusions should not.
